# Account and Integration

This section contains questions about accounts and integrations in Altru Coder.

## Account

### What happens when the trial ends?

When the trial expires:

Your organization will become inaccessible.
No charges will be applied.
If you have any remaining credits in your organization, you can contact Support to request that they be moved to your personal account.

## Integrations

### How do I unlink my GitHub account?

#### Context

You may need to unlink your GitHub account.

This process involves removing the **Altru Coder Connect** application from your GitHub account settings.

#### Answer

To unlink your GitHub account, follow these steps:

1. Go to your GitHub account and navigate to **Settings → Applications → Installed GitHub Apps** or visit [https://github.com/settings/installations](https://github.com/settings/installations)
2. Find **Altru Coder Connect** in the list of installed applications
3. Click **Configure** next to Altru Coder Connect
4. From the configuration page, you can either:
   - **Uninstall** the integration completely, or
   - **Edit** which repositories are connected

{% callout type="tip" %}
If you'd like to reconnect GitHub later, simply open your Altru Coder profile, go to **Integrations**, and connect GitHub again.
{% /callout %}
