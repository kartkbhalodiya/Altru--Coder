### Install directly

1. If you don't have VS Code installed, download it from [code.visualstudio.com](https://code.visualstudio.com/)
2. Then, you can click the button below to install Altru Coder directly from the VS Code Marketplace:

[![Install Altru Coder](https://raster.shields.io/badge/Install%20Altru%20Coder-F8F674?style=for-the-badge)](vscode:extension/altrucoder.altru-coder)

### Install from VS Code Marketplace

1. Open VS Code
2. Press `Ctrl+Shift+X` (Windows/Linux) or `Cmd+Shift+X` (macOS) to open Extensions
3. Search for "Altru Coder"
4. Click **Install**

### Install via Command Line

```bash
code --install-extension altrucoder.altru-coder
```

### Verify Installation

After installation, you should see the Altru Coder icon ({% altruCodeIcon /%}) in the Activity Bar on the left side of VS Code. Click it to open the Altru Coder panel.
